## Important release rule

Do not create a new release merely to insert the previous release's DOI into
files. A new Zenodo-archived GitHub release receives a new version-specific DOI.
Project-level pages should therefore use the concept DOI for the evolving
project, while version-specific citation metadata should use the DOI assigned
to that archived version.
