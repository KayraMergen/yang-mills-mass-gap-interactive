The project uses Zenodo version records for reproducible software snapshots. The
project-level Concept DOI remains stable across versions, while each archived
release receives its own exact DOI.

## Release discipline

- Exact-version citation metadata (`CITATION.cff`, BibTeX, release notes and the
  visible archive link) must use the DOI assigned to that exact release.
- The Concept DOI must not be substituted for an exact-version DOI in a
  reproducibility citation.
- Historical exact DOIs remain valid and must never be relabeled as newer
  versions.
- A GitHub release and a Zenodo version record should describe the same frozen
  software state.

The v6.0.0 record was prepared manually as a new version of the existing Zenodo
record so that its DOI could be reserved and embedded in the archived files
before publication.
