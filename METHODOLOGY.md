# Methodology

## Purpose

This project is a proof-architecture and scientific-audit tool. It is not a
numerical Yang–Mills solver and does not claim to establish the Millennium
Problem.

## Epistemic levels

### E0 — Official target
Statements taken directly from the Clay/Jaffe–Witten problem formulation.

### E1 — Established mathematical framework
Background machinery used by the research program, such as spectral language,
renormalization ideas, and Osterwalder–Schrader reconstruction.

### H1 — Hypothetical research target
Unproved bridges specific to the source presentation, especially the
Representation-Reflective Coercivity / RG reflection-back idea and uniform
continuum transfer.

### T0 — Toy interaction
Normalized UI parameters used only to expose logical dependencies. They are not
physical predictions, lattice measurements, fitted constants, or theorem
certificates.

## Admission rule for claims

A scientific claim added to the console should:
1. receive an epistemic level;
2. name the proof obligation it supports;
3. cite a primary source when it is not original/hypothetical;
4. state whether it is necessary, sufficient, heuristic, or illustrative;
5. state the downstream consequence if it fails.

## What does not count as closing the Clay problem

Within this program, none of the following alone is treated as a solution:
- a finite-lattice gap;
- existence of a dimensional scale Λ_YM;
- clustering without the spectral result;
- a result depending on an uncontrolled global gauge choice;
- a positive toy/simulator lower bound.

The existence/axiomatic side and the positive continuum spectral gap must be
carried together.
